# 双指南针拆分验收

## 安装矩阵

使用 Java 17、Forge 47.4.18，测试的是重映射后的两个安装包，不是开发源码环境。三种安装组合在客户端与独立服务端均通过。

| 安装组合 | 客户端 | 独立服务端 |
|---|---|---|
| 仅探险者 | 通过 | 通过 |
| 仅生物 | 通过 | 通过 |
| 两者同装 | 通过 | 通过 |

每次启动仅发现一个 `compass_runtime`。独立服务端探针验证共享槽位容量为四，第五个申请不获槽，释放后归零。编译及打包依赖检查通过；两包内嵌核心字节相同，均不包含另一产品的实现。生物目录与旧版解码后的 981 条内容一致。

## 完整整合包串联

新优化版独立副本，种子 789123；Xaero World Map 1.39.2、Minimap 25.0.0。Forge 模组警告页由测试探针点击继续，未改第三方模组或屏蔽致命错误。

- 探险者搜索到 `dungeons_plus:leviathan`，XYZ `(-640, 78, 688)`；坐标与 1.2.8 基线一致。放置兼容审核提示在 1.2.8 同样存在。
- 群系搜索到 `minecraft:plains`，XYZ `(136, 100, 200)`。
- 两个永久路径点均在 Xaero 中出现，并在退出后核对磁盘坐标。
- 生物版找到存活的 `minecraft:cow`，UUID `ab829662-6d37-45b0-8e39-2ef4af63ac0f`。服务端复核实际 UUID、类型、维度及群系；大小地图蓝点均执行渲染，地图开关切换通过。
- 两种传送模式在客户端和服务端保持独立：探险者严格、生物直接降级。最终核对槽位及等待队列归零，客户端正常退出。

本轮验证模式配置与传送任务边界，不把它写成实际落地回归。未重跑性能基准、整趟娱乐旅行或逐条图鉴。原整合包、原存档及第三方 jar 未修改。
