# 探险者指南针 统一 1.3.3

Minecraft 1.20.1、Forge、Java 17。支持结构、群系、组搜索、寻找下一个、娱乐旅行、失败报告、日志及成功传送统计。可选 Xaero 联动写永久路径点，不包含生物图鉴或蓝点。

原物品 `explorerscompass:explorerscompass`、NBT、配置及统计继续保留。Forge 元数据版本保留 `1.20.1-1.4.0-unified-` 兼容前缀。客户端和服务端一起升级。见[安装与迁移](../../README.md#安装和迁移)。

## Xaero 永久路径点

搜索成功自动按原始 XYZ 和结果维度创建路径点，名称与指南针显示一致；不需要传送或开启日志。联动需客户端同时装 Xaero 世界地图及小地图（目标组合 1.41.2／26.1.0），没有这两个模组仍可正常使用指南针。若另装了 `compasstomapxaeros` 且重复写入建筑点，可在其配置中设置 `enableStructure = false`，保留自然罗盘的群系联动。

## 1.3.3 传送与灾变

手动传送仅准备落点实际需要的区块。降级允许短落差和浅水，仍防止虚空、卡墙、岩浆和基岩屋顶。宝藏仍对齐箱子同列；原版和 YUNG 要塞优先落在核实的末地门框外侧，旧物品若无门房记录需重新定位。

灾变 3.08 使用实际注册规则进行异步预测，最终仍核对真实结构记录；未知规则可能标为混合兼容。连续第四次同目标区块准备超时会在聊天栏报错。

## 1.3.3 搜索—传送流水线

结构起始与 FULL 区块需求采用同一引用计数代理。两种提前FULL预生成策略在冷态实测出现退化，均已撤回；最终版只在最近性证明完成后准备落点，不以预测代替真实核对。普通落点按完整足迹准备，预备等待与就绪缓存分开计时，成功后40 tick保温不再占核对名额。

八万格范围、最近性、严格/降级与宝藏同列规则不变。真实冷区块仍受第三方生成时间影响；“搜索发起至客户端移动 ≤1秒”是性能验收目标，不能保证。测试进展和未通过项见交付验证记录。与生物版同装时必须使用同核心1.0.2重打包版本，业务功能不变。
