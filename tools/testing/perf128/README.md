# 1.2.8 最小完整实例对比工具

工具单独打包，不进入生产jar。通过正常SearchService请求测量，不放置目标、不跳过真实核对。客户端自动打开测试world128，每次进程只跑一个目标的冷/热两次并退出。目标由`-Dperf128.target`指定，版本标签由`-Dperf128.build`指定。

使用Java17；新优化版全部模组/配置/脚本/资源包的独立副本，母本只保留实际维度及数据包定义、种子改为789123，不复制原存档区块或玩家资料。两版同源母本，各目标重新复制无探索地形，固定(8,100,8)。私有玩家无重力/免伤仅用于稳定起点，不进入生产代码。

每次等待60个tick稳定后发起请求；热请求只清个人排除记录并换新指南针，保留生成及查询缓存。SearchService自动发起的落点预备在请求完成时取消，避免核对工具自身触发额外传送。结构核对只读取已经就绪的STRUCTURE_STARTS Future，群系核对调用实际完整来源。没有真实记录就不标verified。

所有请求上限240秒；终态后检查全局槽位、排队、结构ticket和传送ticket归零。错误立即停止，不能以重新启动抹掉功能失败。

结果JSONL包含终态、实际ID/XYZ、主线程/后台/准备/核对/等待/端到端耗时、样本、候选、区块请求及诊断。prepare_ms是SearchJob模板准备子阶段，不是请求全部初始化；端到端从正常入口调用前开始，包含请求初始化。并发等待与主线程子阶段不能求和当总耗时。版本间不提供的细分指标标N/A，不推断客户端帧率。

构建：Gradle添加`-I tools/testing/perf128/fixture.gradle`，执行`perf128Jar reobfPerf128Jar`。生产发布包不得包含此工具。

补充：天境测试玩家直接从Aether维度的私有NBT启动，避免整合包跨维度入境限制，起点为旁观者/无重力。结构结果可能在工具收到终态前卸载，独立核实会在搜索计时冻结后非阻塞重新准备源区块到STRUCTURE_STARTS，再读取真实起始记录；额外核实耗时不冒充搜索耗时。最初原位读取导致的verified=false已作废，未视为生产算法失败。

最终诊断验收加-Dperf128.metrics=true -Dperf128.runs=3：冷查询断言source_calls>0；相同查询热请求断言query_memo_hit=true且source_calls=0；最后将目标更换为原点当前实际群系，断言origin_cache_hits>0、query_memo_hit=false，避免整次查询缓存掩盖原点缓存退化。每请求独立检查实际群系与票据归零。request_prepare_ms是正常服务入口内部接受/创建/初始化/初次派发所用主线程时间，已包含在main_ms中，不能相加重复计算。
