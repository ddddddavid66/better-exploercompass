# 1.2.7定向验收工具

此工具独立成jar，仅供愚者完整隔离副本；不进入生产发布包。使用`fixture.gradle`构建`fix127Jar reobfFix127Jar`。

加载测试副本world127；通过正常SearchService请求产生受控结构/群系失败，验证报告文件与聊天链接、滚动界面。随后三地牢异步各一次、青铜同步对照；最后分别调用普通与娱乐传送服务确认高度策略、实际群系和票据释放。测试不放置地牢、不授予成就；只调用单站娱乐服务，不跑整趟成就。

受控失败通过测试内存配置radius=0制造，结束立即恢复80000，不更改交付配置文件。玩家仅在测试副本暂设无重力和免伤，避免尚未准备地形时掉入主世界；生产代码不加入这些能力。

测试原始输出为实例内`targeted127-results.txt`，失败不标为通过。启动/验收故障只复测受影响项目。
